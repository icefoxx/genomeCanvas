3. Method in one paragraph

ProfileSeg compares signal profiles around predefined anchors between two conditions with biological replicates. Shape tests use background-corrected, mass-normalised profiles: shape_kernel (an MMD-type kernel distance between condition means, scaled by within-condition spread plus a label-invariant s0), shift (a directional projection on the pooled template's derivative; effect size is a translation-model estimate in bp) and shape_any (per-region Cauchy combination of the two p-values, then one BH). With 2 or 3 replicates per group there are only 3 or 10 label assignments, so per-region p-values come from a null pooled over regions × non-observed assignments. In v3 that pooling is done within quantile strata of each region's total spread (identical under every assignment) when ≥ 200 regions and ≥ 2000 null values per stratum are available. BH runs over all regions.
